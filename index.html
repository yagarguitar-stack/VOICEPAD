ボイスパッド

レッスン中の音声ガイドを、押すだけで鳴らせます。

iPad では、画面を一度押すまで音を出せない決まりがあります。下のボタンを押して始めてください。

使い方

鳴らす

パッドを押すと音が鳴ります。押している間に別のパッドを押せば、重ねて鳴らせます。全部止めたいときは「全部止める」を押してください。

並びを変える

「編集」を押すと編集中になります。パッドを別のパッドまで指でずらすと、入れ替わります。パッドを軽く押すと、表示名・色・音の割り当て・音量を変えられます。もう一度「編集」を押すと元に戻ります。

パッドの数を変える

左上の 3×3 / 4×3 / 4×4 / 5×4 / 6×5 で切り替わります。それぞれ別々に並びを覚えています。

組み合わせを保存する

並びを作ったら「保存」を押し、名前を付けます。あとから左の欄で選べば、その並びに戻ります。同じ名前で保存すると上書きします。

保存したあとにパッドを動かすと「未保存」と出ます。そのままにしておくと、次に選び直したときに動かすまえの並びに戻ります。残したいときは、もう一度「保存」を押してください。

組み合わせはパッドの数ごとに分かれています。4×3で作ったものは、4×3のときだけ出てきます。

別の端末に持っていく

組み合わせはその端末にだけ残ります。「書き出し」でファイルに出し、AirDropなどで送った先で「読み込み」を押すと、同じ組み合わせが使えます。同じ名前のものは上書きされます。

音声を増やす

音声ファイルは voices フォルダに、番号だけの名前で入れます。01.wav でも 001.wav でも構いません。VOICEVOX の 設定 → オプション → 書き出しファイル名パターン を $連番$ だけにしておくと、その名前で書き出されます。

  1. パソコンの VOICEVOX でずんだもんに喋らせ、音声を書き出します。
  2. 書き出したファイルの名前を、続きの番号（36.wav など）に変えて voices フォルダに入れます。
  3. HTML の一覧の末尾に、その表示名と色を1行足します。

iPad から直接足したいときは、編集中にパッドを押して「この端末から音声を追加」を選んでください。追加した音声はこの端末だけに残ります。

反応を速くする

音声ファイルの先頭には、書き出したときの無音が入っていることがあります。そのまま鳴らすと、押してから声が出るまで遅れて感じられます。このアプリは読み込むときに声の始まる位置を自動で探し、そこから鳴らします。音声を切り詰める作業は要りません。

頭が切れて聞こえる音声があれば、これを切って、そのファイルだけ手元で切り詰めてください。

音が出ないとき

iPad 本体の音量と、消音の設定を確かめてください。それでも鳴らないときは、画面を読み込み直して「はじめる」を押し直してください。

ホーム画面に置く

Safari の共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように全画面で開けます。

音声の読み上げには VOICEVOX:ずんだもん を使用しています。
