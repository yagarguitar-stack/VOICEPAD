使い方

鳴らす

パッドを押すと音が鳴ります。押している間に別のパッドを押せば、重ねて鳴らせます。鳴っている間はパッドの色帯が光り、下に PLAYING と出ます。まとめて止めたいときは STOP ALL を押してください。

並びを変える

EDIT を押すと編集中になります。パッドを別のパッドまで指でずらすと入れ替わり、軽く押すと設定が開きます。設定では表示名・色・鳴らす音・そのパッドの音量を変えられます。もう一度 EDIT を押すと演奏の画面に戻ります。

パッドの数を変える

上の 3×3 / 4×3 / 4×4 / 5×4 / 6×5 で切り替わります。それぞれ別々に並びを覚えています。

組み合わせを保存する

並びを作ったら SAVE を押し、名前を付けます。あとから左の欄で選べばその並びに戻ります。同じ名前で保存すると上書きします。

保存したあとにパッドを動かすと MODIFIED と出ます。そのままにしておくと、次に選び直したときに動かすまえの並びに戻ります。残したいときはもう一度 SAVE を押してください。

組み合わせはパッドの数ごとに分かれています。4×3で作ったものは4×3のときだけ出てきます。PRESETS を押すと、この行を隠せます。

別の端末に持っていく

組み合わせはその端末にだけ残ります。EXPORT でファイルに出し、AirDropなどで送った先で IMPORT を押すと同じ組み合わせが使えます。同じ名前のものは上書きされます。

音声を増やす

音声ファイルは voices フォルダに、番号だけの名前で入れます。01.wav でも 001.wav でも構いません。VOICEVOX の 設定 → オプション → 書き出しファイル名パターン を $連番$ だけにしておくと、その名前で書き出されます。

  1. VOICEVOX で音声を書き出します。
  2. 続きの番号（36.wav など）にして voices フォルダに入れます。
  3. この HTML ファイルの上のほうにある一覧の末尾に、表示名と色を1行足します。

この端末にだけ足したいときは、編集中にパッドを押して「この端末から音声を追加」を選んでください。

反応を速くする

音声ファイルの先頭には、書き出したときの無音が入っていることがあります。そのまま鳴らすと、押してから声が出るまで遅れて感じられます。このアプリは読み込むときに声の始まる位置を自動で探し、そこから鳴らします。音声を切り詰める作業は要りません。

頭が切れて聞こえる音声があれば、これを切って、そのファイルだけ手元で切り詰めてください。

キーボード

パッドは Tab で選び、Enter か Space で鳴らせます。画面が開いているときは Esc で閉じ、名前の入力は Enter で決定します。

音が出ないとき

本体の音量と消音の設定を確かめてください。それでも鳴らないときは、画面を読み込み直して START を押し直してください。

ホーム画面に置く

Safari の共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように全画面で開けます。

音声の読み上げには VOICEVOX:ずんだもん を使用しています。
